# Contributing

The public GitHub repository is a read-only mirror. Development and review
happen in a private canonical repository, so pull requests opened on GitHub are
closed automatically.

If you want to discuss a change, contact the maintainer through the same route
that pointed you to this mirror before preparing a pull request.

Contributions are accepted only on terms that preserve the project owner's
ability to maintain, distribute, relicense, and offer alternate licenses for
Switchyard.

By submitting a contribution, you agree that either:

- you assign copyright in the contribution to the project owner; or
- you grant the project owner a perpetual, worldwide, irrevocable,
  transferable, sublicensable, royalty-free license to use, modify, distribute,
  relicense, and otherwise exercise copyright in the contribution.

If you cannot contribute on those terms, do not submit the contribution unless
you have a separate written agreement with the project owner.
